# Telegram 新闻推送：Windows 免费备用定时器

仅用于 dalulu05168/github-workflows-telegram-test.yml-，不涉及其他项目。

## 安装

1. 解压整个包到固定目录（例如 D:\TelegramNews），不要在压缩包内直接运行，不要移动已安装的目录。
2. 双击 `install.cmd`。内含官方 GitHub CLI，无需另装 Python、Node 或填写 Telegram 密钥。
3. 首次按提示在 GitHub 官方网页授权仓库所属账号；不要把授权码、密码或 token 发到聊天。
4. 显示 `INSTALLED` 后，约一分钟开始检查，之后每十分钟检查。电脑必须开机、已登录、保持唤醒且联网；不修改你的休眠设置。

任务名为 `TelegramFinanceNewsFallback`。重复安装更新同名任务，不新增多份。任务以当前 Windows 用户运行，不要求保存 Windows 密码；组织安全策略仍可能限制任务注册，安装失败会明确显示错误。

## 工作方式

- 按罗马尼亚和法国各自本地时间、夏令时自动判断原仓库发布窗口：07:30–07:59，以及08点起每小时的30–59分。窗口外只记本地状态，不调用新闻工作流。
- 原工作流已有排队/运行或最近十分钟检查过，备用调度跳过；原发送账本继续控制去重。
- 本机只触发 GitHub 工作流，采集、筛选、翻译、发送及 Telegram 密钥仍在 GitHub。
- 无合格新闻不凑数、不发送。`DISPATCH_ACCEPTED` 仅代表触发请求接受；实际发送看工作流的 News delivery status 和 Telegram 收件结果。GitHub 排队仍可能延迟。
- 本机使用你本人 GitHub 登录凭据（由官方 CLI 管理）；包内不包含任何账户凭据。

## 检查与卸载

双击 `status.cmd` 查看任务状态、最近检查日志及正式运行列表。日志保存在 `logs/dispatcher.log`，超过1MB滚动保留一份。
双击 `uninstall.cmd` 仅删除这个本机任务，不删除仓库、不改 Telegram 配置、不退出 GitHub 账号。

## 验证范围

已执行 PowerShell 语法解析、离线调度决策测试与仓库 Python 回归测试；尚未在你的 Windows 实机安装。只有你完成授权并看到任务实际运行后，才能确认本机调度已接通。官方 CLI 包来源及校验值见 `GitHub-CLI-source.json`；许可证随包附带。
