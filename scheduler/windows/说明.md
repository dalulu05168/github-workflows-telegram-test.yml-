# 免费Windows定时兜底（尚未安装到用户电脑）

用途：绕开GitHub自然cron未唤醒的问题，在原发布窗口每10分钟检查一次同一正式工作流。发送、翻译、去重和Telegram密钥仍留在GitHub，不另建机器人。

1. 安装免费GitHub CLI： https://cli.github.com/ 。在自己的终端运行 `gh auth login`，使用有权限操作这个仓库的账号；不要把token发到聊天。
2. 保留整个文件夹，右键PowerShell运行 `install.ps1`。也可在终端运行 `powershell -ExecutionPolicy Bypass -File .\install.ps1`。
3. 电脑需开机、已登录且联网。安装器不修改电源休眠设置，关机后不能触发。
4. 查看任务计划程序中的 `TelegramFinanceNewsFallback`。已有任务运行或最近10分钟检查过则跳过，不干扰自然cron恢复；发送账本仍防止重复发送。
5. 停止：在任务计划程序禁用或删除该任务；或运行 `Unregister-ScheduledTask -TaskName TelegramFinanceNewsFallback -Confirm:$false`。

调度请求被接受不代表有新闻或Telegram送达。无合格新闻仍不发送。脚本仅离线测试逻辑；不能宣称已经在用户Windows安装验证。
